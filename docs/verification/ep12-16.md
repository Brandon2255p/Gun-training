# Verification record: episodes 12–16 (Module 4: Fundamentals of Shooting)

Checked against the page images `source/pages/s028–s048.jpg` (printed pp. 26–42) and the formative exam
`s083–s086` (pp. 75–78). Transcriptions were used as a guide only: every quoted sentence was compared with the scan.
Every figure crop was rendered with ImageMagick and inspected. `python3 scripts/lint.py` passes on all five files and
each file passes `python3 -m json.tool`.

Changes that affect every episode:
- **Rule-card labels.** Without a `label`, a rule card is shown as "Rule". The book calls none of these statements
  a rule except the "golden rule of aiming", so every `rule` scene now has a label (listed per episode below).
  SCRIPT_GUIDE requires this.
- **File formatting.** The files were rewritten with `json.dumps(indent=2)`, so short arrays now take one line per
  item. The structure has not changed.
